# Підхід: щоденник залу

Записуєш вправу, вагу й повтори. Наступного разу поруч бачиш, що робив минулого тижня, і стрілку: більше чи менше.

- Головний екран: що зроблено цього тижня і що ще треба повторити з минулого.
- Вибір вправи: 33 вправи за групами м'язів + можна додати свою.
- Екран вправи: підходи «сьогодні» поряд з «минулого разу», кнопки ±2,5 кг і ±1 повтор, графік прогресу, історія.
- Усе зберігається на телефоні, без акаунтів і інтернету.

Кольори груп взято з олімпійських млинців: ноги червоні (25 кг), спина синя (20), груди жовті (15), плечі зелені (10), руки білі (5).

## Запустити на своєму телефоні (10 хвилин)

1. Встанови [Node.js](https://nodejs.org) (версія LTS).
2. Розпакуй архів, відкрий термінал у папці `gymlog` і виконай:
   ```bash
   npm install
   npx expo start
   ```
3. Встанови на телефон застосунок **Expo Go** (Google Play або App Store).
4. Відскануй QR-код з терміналу: Android через Expo Go, iPhone через камеру. Телефон і комп'ютер мають бути в одній Wi-Fi мережі.

Змінюєш код, зберігаєш файл, і застосунок на телефоні оновлюється сам.

Хочеш подивитися з прикладом даних: `EXPO_PUBLIC_DEMO=1 npx expo start` (на Windows: `set EXPO_PUBLIC_DEMO=1 && npx expo start`).

## Випуск у магазини

Збірка йде в хмарі через EAS, Mac не потрібен.

```bash
npm install -g eas-cli
eas login                 # безкоштовний акаунт на expo.dev
eas build:configure
eas build -p android      # файл .aab для Google Play
eas build -p ios          # потрібна підписка Apple Developer
eas submit -p android     # або завантаж .aab вручну в Play Console
```

Перед випуском:
- Заміни іконки в `assets/` на свої (1024×1024).
- Перевір `package` і `bundleIdentifier` в `app.json`: вони мають бути унікальні, наприклад `com.твоєімʼя.pidkhid`.
- Політика конфіденційності: застосунок нічого не надсилає в інтернет, так і напиши.
- Google Play для нового особистого акаунта: 12 тестувальників на 14 днів закритого тесту.
